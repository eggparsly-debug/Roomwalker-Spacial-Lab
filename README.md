# Roomwalker

A VST3 effect that places a track's sound inside a simulated 3D room and moves it along a path. It is a binaural spatializer and a spatial reverb in one: every Roomwalker in a project shares the same room.

## Install (Windows)

1. Open the newest successful run under [Actions](../../actions/workflows/build.yml) and download `Roomwalker-VST3-Windows` from its Artifacts section.
2. Unzip it and copy `Roomwalker.vst3` to `C:\Program Files\Common Files\VST3`.
3. In Cakewalk, rescan VST plugins and add **Roomwalker** to a track's effects bin.

The plugin window needs the Microsoft Edge WebView2 Runtime, which is already on current versions of Windows.

## Using it

- Add Roomwalker to each track you want in the room. Every instance joins the same room, and any instance's window can edit all of them.
- **Tempo sync** moves a sound along its path in time with the project.
- **DAW automation** moves it with the **Path Position** parameter. Choose that mode on the Track tab, then draw the envelope in Cakewalk.
- Input Gain, Direct Sound, Early Reflections, Reverb Tail and Pitch Bend can also be automated.
- Rooms, paths and settings save with the project.

## Building

Push to GitHub and the Actions workflow builds the VST3, or build locally with CMake 3.22+ and Visual Studio 2022:

```
cmake -S . -B build -A x64
cmake --build build --config Release --target Roomwalker_VST3
```

## Layout

| Path | What it is |
|---|---|
| `src/core` | The audio engine in plain C++ |
| `src/plugin` | The JUCE plugin, shared room and window bridge |
| `src/ui/index.html` | The plugin window, generated by `tools/build_ui.py` |
| `reference` | The browser prototype the engine is checked against |
| `tools` | Null-test renderers, the self-test and the plugin host test |
